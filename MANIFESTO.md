# ASL Language Technical Manifesto

> [!NOTE]
> This document covers the design of the ASL language and compiler, and says where each aim stands today.

> **"Code generated by agents. Checked before it runs. Compiled to the runtime it needs."**

---

## 1. Why AgentScript Exists

Production languages were designed for human keyboards and IDEs, and each has a trap for a model that writes left to right: invisible indentation (Python), non-local lifetimes (Rust), silent missing properties (JavaScript), repeated error boilerplate (Go). Agents spend part of their budget on the repair loops these cause.

**ASL aims to remove that layer.** It is an immutable S-expression language with explicit effect boundaries. Today the stage-0 C host (`host/out/asl-host`) checks and runs it, and `asl-target-llvm` lowers a linked program to LLVM IR for native code and `wasm32-unknown-unknown`. Other targets are prototypes.

---

## 2. Core Principles

### 1. Structure that cannot be misread
Forms are balanced trees: no precedence, semicolons or significant indentation inside a form to track. A function header is a bare column-0 line (`fn name a: Int64 -> Int64`) with its body below; the body closes only its own parentheses. The goal is a valid AST on the first pass.

### 2. No silent `null`
There is no `null` or `undefined`. Optional values are `(some v)` / `(none)`, failures `(ok v)` / `(err e)`, taken apart with `mt`, and `asl-host check` rejects an `mt` over an enum that misses a variant (ERR_MATCH_NONEXHAUSTIVE).

### 3. Explicit effects (`!`)
Logic is pure. A function that touches disk, network, terminal or clock is marked `fn ! name ...` or named with a trailing `!`, and `asl-host check` rejects an unmarked one (ERR_EFFECT_UNMARKED), so a refactor cannot add a side effect unseen.

### 4. One notation for code and messages
Code, contracts, tool payloads and wire messages are all ASN (`(:task :id t1 :status :running)`), so nothing is translated between them. What this saves against JSON is a measurement, not an assumption: `bench/publishedClaims.asn` lists each published figure with its status, and the general ASN-against-JSON range is marked unmeasured there.

### 5. Small, sandboxed WebAssembly
`asl-target-llvm` builds `wasm32-unknown-unknown` modules that import four host functions (`asl.write`, `asl.exit`, `asl.nowNs`, `asl.trap`). A builtin that needs files, environment, sockets or another clock is absent on that target and the build fails with ERR_CAPABILITY_ABSENT, so a module can only do what its host hands it. [aslang.dev](https://aslang.dev) is built this way from `web/`.

### 6. Names at the lowest measured cost
Identifiers are camelCase whole words and the module carries the domain; predicates end in `?`, effects in `!` (`listLength`, `stringContains?`, `fileRead`). Among names that carry the meaning, the measured cheapest wins (`MeasuredCostDecidesTheName`, the basis of the `names` rule in `grammar/rules.asn`).

---

## 3. Code Is Compiled Thought

A model has no retinas; it reasons in trees. S-expressions serialize the tree directly: the body of `fn inc x: Int64 -> Int64` is `(+ x 1)`, which parses unambiguously with no visual decoration.

### Migration by coexistence (a plan)
Adoption should not need a rewrite: one kernel at a time moves into ASL, ASL generates the bindings, and the existing test suite decides whether the move holds. No tool does this today.

---

## 4. One Source, Several Targets

One ASL module (`.asl`) is meant to compile to every target with the same semantics, checked by differential tests rather than asserted. Today that holds for one route: native and wasm32 through LLVM IR. The self-hosted compiler `asl1` has a committed seed for `arm64-apple-darwin` only, and self-hosting is in progress. The TypeScript, WAT and other source-to-source targets (`packages/asl-target-*`) are prototypes.

---

## 5. Evidence

Every figure the project publishes is a row in `bench/publishedClaims.asn` with its status (`:measured`, `:measuredUntracked`, `:budget`, `:specConstant` or `:unmeasured`) and what stands behind it. An `:unmeasured` figure must not be cited as a result.

---

## 6. Quick Start

AgentScript is not released and the installer is under development. From a checkout:

```bash
sh host/build.sh                       # builds host/out/asl-host
host/out/asl-host check file.asl       # names, arity, enums, types it knows, effects
host/out/asl-host test fileTest.asl    # runs runTests; exit 0 and the assert count are the evidence
host/out/asl-host run file.asl         # calls main
```

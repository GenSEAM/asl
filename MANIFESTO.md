# ASL Language Technical Manifesto

> [!NOTE]
> This document covers the design of the ASL language and compiler. The engineering pillars are in the root `/MANIFESTO.md`.

> **"Code generated by agents. Checked before it runs. Compiled to the runtime it needs."**

---

## 1. Why AgentScript Exists

Production languages were designed for human keyboards and IDEs, and each has a trap for a model that writes left to right: invisible indentation (Python), non-local lifetimes (Rust), silent missing properties (JavaScript), repeated error boilerplate (Go). Agents spend part of their budget on the repair loops these cause.

**ASL aims to remove that layer.** It is an immutable S-expression language with explicit effect boundaries, compiled to WebAssembly, TypeScript, Rust and Python.

---

## 2. Core Principles

### 1. Structure that cannot be misread
S-expressions are balanced trees by construction: no precedence, semicolons or indentation to track. The goal is a valid AST on the first pass.

### 2. No silent `null`
There is no `null` or `undefined`. Optional values are `(Option T)` with `(some v)` / `(none)`, fallible ones `(Result T E)` with `(ok v)` / `(err e)`, and `(match ...)` is checked for exhaustiveness.

### 3. Explicit effects (`!`)
Logic is pure. Functions that touch disk, network, terminal or clock carry the effect marker `!`, so a refactor cannot add a side effect unseen.

### 4. One notation for code and messages
Code, contracts, tool payloads and wire messages are all ASN (`(:task :id t1 :status :running)`), so nothing is translated between them. What this saves against JSON is measured per format in `asl/bench/asn_tokens.lock`, not assumed.

### 5. In-memory WebAssembly execution
ASL compiles to `wasm32-wasip1` and runs modules in memory with page-level isolation, instead of starting a container.

### 6. Names at the lowest measured cost
Identifiers are whole words and the namespace carries the domain (`(txt/clean doc)`); predicates end in `?`, effects in `!`, conversions use `->`. Among names that carry the meaning, the measured cheapest wins (`MeasuredCostDecidesTheName` in `.asl/mem/principles.asn`).

---

## 3. Code Is Compiled Thought

A model has no retinas; it reasons in trees. S-expressions serialize the tree directly: `(df calc [(x I64)] (+ x 1))` parses unambiguously with no visual decoration.

### Migration by coexistence
Adoption does not need a rewrite. Through multi-runtime insets (`(:stage :calc :runtime :wasm ...)` / `(:inset :py ...)`) one kernel at a time moves into ASL, ASL generates the bindings, and the existing test suite decides whether the move holds.

---

## 4. One Source, Several Targets

One ASL core module (`.asl` / `.agentscript`) compiles to WebAssembly, TypeScript, Rust and Python. The goal is the same semantics on every target, checked by differential tests rather than asserted.

---

## 5. Evidence

Published figures are grounded in lock files (for example `asl/prelude/coverage.lock`) and `./bin/asl audit gates` fails on one with no source.

---

## 6. Quick Start

```bash
# Scaffold a new project
asl init demo-project --template wasm

# Typecheck and build
cd demo-project
asl check src/main.agentscript
asl build src/main.agentscript --target wasm -o dist/main.wasm
```

# AgentScript Manifesto: The Deterministic Language for Autonomous AI Agents

> **"Code generated by Agents. Executed in WebAssembly at native speed. Bridged everywhere."**

---

## 1. The Core Motivation: The Token Tax of Human Syntax

Modern programming languages were designed for human eyeballs, text editors, and manual typing. When applied to autonomous AI agents and large language models (LLMs), these human-centric designs break down:

1. **The Syntax Tax:** LLMs waste up to 40% of their compute and prompt budget fighting whitespace indentation errors in Python, borrow-checker lifetime disputes in Rust, `undefined is not a function` drift in TypeScript, and repetitive `if err != nil` rituals in Go.
2. **The Context Window Bloat:** Providing full dependency source code to an agent quickly exhausts LLM context windows, degrading reasoning and inflating API costs.
3. **The Sandbox Dilemma:** Executing agent-generated code safely today requires heavy Docker containers or microVMs with 100–300ms cold starts, or risky un-sandboxed native evaluation.

**AgentScript was created to solve these root causes.** It is not a speculative experiment; it is a hardened, strongly typed, S-expression intermediate language built specifically for single-pass agent code generation and zero-overhead WebAssembly execution.

## 2. The Four Foundational Pillars

```
┌───────────────────────────────────────────────────────────────────────────────────┐
│                                 AGENTSCRIPT CORE                                  │

│   Exhaustive sum types    │   Interface compression   │   <1ms instant execution  │
│   Explicit effect (!)     │   Structured AST MCP tools│   Isolated memory pages   │
└───────────────────────────┴───────────────────────────┴───────────────────────────┘
```

### Pillar 1: Single-Pass Deterministic Generation
- **Balanced by Construction:** S-expressions eliminate indentation ambiguity and multi-line parsing traps.
- **Exhaustive Pattern Matching:** Closed unions (`defenum`) require total handling at compile time; runtime null pointer exceptions are structurally impossible.
- **Explicit Effect Tracking (`!`):** Pure functional logic and side-effecting host operations (file I/O, network, clock) are strictly demarcated.

### Pillar 2: -78% Context Window Overhead via Interface Compression
- The AgentScript interface compressor (`asex_compress_module`) strips internal function bodies into stubbed signatures while preserving typed contracts, schemas, and docstrings.
- **Measured Reality:** A 650-token module compresses to 142 tokens (**-78.1% context savings** across multi-agent loops).

### Pillar 3: WebAssembly as the Primary Production Target
- WebAssembly (`wasm32-wasip1`) is the core execution target.
- 64KB memory page granularity, zero-overhead bounds checking, instant in-browser and edge execution via pure in-memory WASI preview1 host shims.

### Pillar 4: Multi-Target Ecosystem Glue
- AgentScript acts as the universal glue between Object-Oriented, Functional, and Procedural worlds:
  - **(defschema ...)** compiles to immutable Classes in TypeScript/Python, Structs in Rust/Go/Swift.
  - **(defenum ...)** compiles to algebraic sum types and exhaustive match statements.
  - **(defun ! ...)** compiles to safe goroutines, async Node/WASI routines, and embedded loops.

You write ASL. Two complete programs show the whole language:

fn parity n: Int64 -> String
  (cond
    ((< n 0) (str "minus " (parity (- 0 n))))
    ((= (mod n 2) 0) (str (stringFromInt64 n) " is even"))
    (else (str (stringFromInt64 n) " is odd")))

schema Cart { owner: String total: Int64 }

enum Event (add price: Int64) (clear)

fn applyEvent c: Cart e: Event -> (Result Cart String)
  (match e
    ((clear) (ok (with c :total 0)))
    ((add price)
      (if (< price 0)
        (err "negative price")
        (ok (with c :total (+ c.total price))))))

fn firstOver xs: (List Int64) limit: Int64 -> (Option Int64)
  (match (listHead xs)
    ((none) (none))
    ((some h)
      (let [(rest (listDrop xs 1))]
        (if (> h limit) (some h) (firstOver rest limit)))))

Pitfalls, most frequent first:
1. The fn header is a bare line; the body is ONE form in parentheses, never a bare cond, match or let.
2. Equality is =, inequality !=, remainder mod; == and % do not exist.
3. Write the code at once, without long deliberation; close each parenthesis exactly once.
4. (listAppend xs (list x)) joins two lists; (list) is empty; there is no [] literal.
5. listHead listTail listGet listMax mapGet return (some v) or (none): unwrap by match or (optionOr e default); (listDrop xs 1) is a plain List.
6. Builtins are camelCase, type first: listLength listReverse listSort listContains? listSum stringLength stringChars stringSplit stringJoin; (fold (fn [acc x] (+ acc x)) 0 xs); + never joins strings, str does.

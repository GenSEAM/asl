n ASL file is a module header, then items starting in column 0: (module ws/name :x [exported names] :i [(other/module :a alias)]). Imports name the module a file declares, not its path. A standalone program needs no header: its column-0 code forms run in order as the entry like a shell script, with args bound (argInt args 0 7, argStr args 1 "x") and the file's fns visible; a top-level (let [(x e)]) binds x for the forms after it, unwrapping an ok, and a form that checks as (err e) stops the script with one ASN line on stderr naming its form number, line and e, and exit 1; (use pkg/mod) imports mod as mod/; a #! first line is skipped, so asl FILE, ./FILE, asl -e 'code' and asl - run it; only the entry may hold code, importing it is ERR_TOPLEVEL_IN_LIBRARY. A headerless file that defines main is a script too, and fn main with no -> binds args, returns (ok ()) and ends on a Unit line; lambda parameters need no types, (fn [x] (* x 2)). Docs are not in source: each lives as a (:doc :symbol "path#name" :text "...") row in the package doc.asn, and the reader rejects :d docstrings and prose ; comments. A function is a bare line, fn name a: Int64 b: String -> Bool, with its body indented below; that line is not a form, so the body closes only its own parentheses. Each bracket kind pairs exactly: ( ) forms, [ ] lists, { } records. enum Shape (circle r: Int64) (square side: Int64) makes positional constructors, taken apart by (match s ((circle r) ...) ((square a) ...)); patterns nest one level. A record field reads as x.f, chains as a.b.c, and on an expression as (expr).f; (with x :k v) is a copy of record x with field k set to v. (let [(a 1) (b (+ a 1))] body) binds in sequence; (fn [x] body) is a value; cond ends with (else v). Conditions, and, or, not and assert take only true or false. Int and Float never mix; overflow and division by zero trap. There is no nil, exception or try: listHead, listTail, listGet, listSlice, stringSlice and mapGet return (some v) or (none), failures are (err e), unwrapped by match, optionOr or resultOr. Builtins are camelCase like user names, predicates end in ?: listLength, stringContains?, some?; len and head do not exist; + is not a value. A test exports runTests, returning true after at least one (assert cond "msg") or refute. The stage-0 host asl/host/out/asl-host enforces all this before running, and (:test), (:check), asl test and asl check of an .asl file and asl eval run on it (asl eval prints a keyword-headed form back as ASN data); a bare asl test or asl check sweeps every discovered suite or tracked file on it, and the lenient asl-core runner is retired. After an ASL edit run asl/host/out/asl-host check FILE, then test FILE: exit 0 and the executed assert count are the evidence; a test is (module ws/t :x [runTests]) with fn runTests -> Bool ending true after (assert c); asl run FILE or asl FILE runs a program; asl '(:help :builtin stringTo)' lists builtins by name, else by doc, with types.

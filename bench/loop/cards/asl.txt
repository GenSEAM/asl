The package is AgentSlang (ASL), a statically typed Lisp-like language. A file is a module header, (module pkg/name :x [exported names] :i [(other/module :a alias)]), followed by items that start in column 0. A function is a bare header line, fn name a: Int64 b: String -> Bool (fn ! name when it has effects), with its body indented below; the header line is not a form, so the body closes only its own parentheses. A name imported from another module is written alias/name, and only names in that module's :x list can be imported. (let [(a 1) (b (+ a 1))] body) binds in sequence; (if c a b) and (cond (test value) (else value)) branch; (match r ((ok v) ...) ((err e) ...)) and (match o ((some v) ...) ((none) ...)) take values apart. There are no exceptions and no nil: a failure is (err "message"), a success (ok value); listGet and listHead return (some v) or (none), unwrapped by optionOr. Int64 and Float64 never mix, int64ToFloat64 converts. Conditions are only true or false. Records are (schema Name (:f field Type)), built as (Name :field v), read as x.field. A test file exports runTests, which returns true after (assert cond "message") calls. Every bracket pairs exactly: ( ) forms, [ ] binding, parameter and export lists.

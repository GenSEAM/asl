AgentSlang (asl) runs batch file operations on the git repository containing the working directory. Reach for it for targeted symbol reads instead of dumping files, definitions plus uses in one step, and atomic edits validated before disk commit. Edits and writes stage in a session buffer on disk that persists across calls; (:diff), (:check) and (:test) see staged content, (:flush) writes it, (:discard) drops it. asl exits 0 on success, 1 on rejected forms, and 2 on syntax or balance errors. Forms can also come from a file, asl -f FILE, or from stdin, asl -, with the same batch and exit codes; a heredoc with a quoted delimiter (asl - <<'ASN') passes a form holding a single quote, which asl '...' cannot. Discover operations via (:tools) for the full registry, (:help :op <name>) for signatures and errors, and (:help :topic <topic>) for staging, txn, batch, receipts, and errors. Example: asl '(:read :file "src/app.py" :symbol "greet") (:edit :file "src/app.py" :old "return 1" :new "return 2") (:check :file "src/app.py") (:flush)'.

An ASL file is a module header, then items starting in column 0: (module ws/name :x [exported names] :i [(other/module :a alias)]). Imports name the module a file declares, not its path. Docs are not in source: each lives as a (:doc :symbol "path#name" :text "...") row in the package doc.asn, and the reader rejects :d docstrings and prose ; comments. A function is a bare line, fn name a: Int64 b: String -> Bool, with its body indented below; that line is not a form, so the body closes only its own parentheses. Each bracket kind pairs exactly: ( ) forms, [ ] lists, { } records. enum Shape (circle r: Int64) (square side: Int64) makes positional constructors, taken apart by (mt s ((circle r) ...) ((square a) ...)); patterns nest one level. A record field reads as x.f, chains as a.b.c, and on an expression as (expr).f; (with x :k v) is a copy of record x with field k set to v. (let [(a 1) (b (+ a 1))] body) binds in sequence; (fn [x] body) is a value; cond ends with (else v). Conditions, and, or, not and assert take only true or false. Int and Float never mix; overflow and division by zero trap. There is no nil, exception or try: listHead, listTail, listGet, listSlice, stringSlice and mapGet return (some v) or (none), failures are (err e), unwrapped by mt, optionOr or resultOr. Builtins are camelCase like user names, predicates end in ?: listLength, stringContains?, some?; len and head do not exist; + is not a value. A test exports runTests, returning true after at least one (assert cond "msg") or refute. The stage-0 host asl/host/out/asl-host enforces all this before running, and (:test), (:check), asl test and asl check of an .asl file and asl eval run on it (asl eval prints a keyword-headed form back as ASN data); a bare asl test or asl check sweeps every discovered suite or tracked file on it, and the lenient asl-core runner is retired. After an ASL edit run asl/host/out/asl-host check FILE, then test FILE: exit 0 and the executed assert count are the evidence; a test is (module ws/t :x [runTests]) with fn runTests -> Bool ending true after (assert c); asl run FILE runs a program; asl '(:help :builtin stringTo)' lists builtins by name, else by doc, with types.

Public ops: tools, help, eval, mem, doc, read, query, edit, write, diff, flush, discard, check, test, fix, txn

# @genseam/search (ASL Metasearch & Proxy Pool)

Decentralized SearXNG metasearch aggregator with zero-drop proxy rotation, URL deduplication, and -78% RAG context compression for autonomous AI agents.

## Installation
```bash
asl get github.com/GenSEAM/search
```

## Features
- **Multi-Engine Aggregation:** Queries SearXNG instances across Google, Bing, DuckDuckGo, arXiv, and GitHub.
- **Proxy Pool Health Checks:** Type-safe proxy rotation with automatic retry and backoff for degraded nodes.
- **RAG Context Compressor:** Strips noisy HTML boilerplate and formats clean markdown context for LLMs.

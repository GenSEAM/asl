# @genseam/asl-harness

Universal pluggable multi-modal agent runtime supporting Code Generation, Browser Automation, Computer-Use (OS/Terminal), Chat RAG, and Metasearch with sub-millisecond in-memory Wasm execution.

## Installation
```bash
pnpm add @genseam/asl-harness
```

## Adapters
- `CodeEngineAdapter`: AST synthesis and in-memory WebAssembly verification.
- `BrowserAdapter`: Headless browser viewport and DOM tree extraction.
- `ComputerUseAdapter`: Desktop OS execution and signed build receipts.
- `ChatRAGAdapter`: Vector similarity memory recall and prompt compression.
- `MetasearchAdapter`: Decentralized SearXNG search aggregation.

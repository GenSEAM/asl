# Compact ASL — superseded

> **Status: historical.** Everything this page proposed either shipped as the Nano projection or
> was rejected. Read [`docs/NANO_SYNTAX.md`](NANO_SYNTAX.md) for orientation and
> [`AGENT_SPEC_CORE.md`](../AGENT_SPEC_CORE.md) §2.1 for the normative text. It is kept because it
> records why the compact spellings exist, which is not derivable from the grammar.

## What it argued

Early AgentScript spelled everything out — `defschema`, `defun`, `Float64`,
`(:field name Type doc)` — which made a small record declaration roughly twice the length of its
TypeScript equivalent. For a language whose whole purpose is to be generated by a model paying per
token, that is the wrong trade, and the argument was that shorter spellings could be added without
giving up single-pass parsing or the closed vocabulary.

That argument was accepted. `df`, `dfs`, `dfe`, `mt`, `:d`, `:x`, `:i`, `:a`, `:f`, `:c`, `I64`,
`F64` and `Str` are the result, and both grammars accept them.

## What it proposed and the language does NOT have

These appear in the original draft of this page and parse under neither grammar. They are recorded
here so that nobody reads an old copy and writes them:

| Proposed | Status |
|---|---|
| `(schema Point [x:Num y:Num])` — inline `name:Type` field pairs | **Rejected.** A field's doc string is mandatory (`AGENT_SPEC_CORE.md` §4.1); the compact form has nowhere to put one, and the doc string is the part a model actually reads. |
| `p2.x` — dotted field access | **Rejected.** Field access is `(.-x p2)`. A dotted form collides with the FFI method syntax the language is keeping free (`SPEC_REVIEW.md` C3). |
| `hypot`, `pow`, `sqrt` | **Not in the vocabulary.** §6 is closed and `grammar/closure_audit.py` enforces it. |
| `(def distance [p1:Point p2:Point] -> Num ...)` | Half shipped: `def` is an accepted head, the `name:Type` parameter form is not. Parameters are `[(p1 Point) (p2 Point)]`. |
| `(str "Hello " user "!")` | **Shipped.** `str` is variadic over strings. |

## The one thing to carry forward

The measurable claim in the original was that compact spellings cut prompt tokens. The project now
holds itself to `DESIGN.md` §5 on that: a number on a public page must be reproducible by a
command. `bench/token_frames.py` is the pattern — it counts with `cl100k_base` and a lock file
fails when the figure moves. No percentage belongs on this page without one.
